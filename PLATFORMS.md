# 🛡 Рекомендовані Платформи для Спільноти

> "Використовуй інструменти, які поважають твою приватність та підтримують свободу"

## ✅ Рекомендовані Альтернативи

### 1. Signal (Найкраща для Messaging)

**Чому ТАК:**

- ✅ E2E encryption за замовчуванням
- ✅ Open-source (код перевірений спільнотою)
- ✅ Мінімум метаданих
- ✅ Фінансується некомерційною організацією
- ✅ Використовується журналістами, активістами

**Функції:**

- Чати 1-на-1
- Групові чати (до 1000 учасників)
- Голосові та відео-дзвінки
- Зникаючі повідомлення
- Нотатки для себе

**Мінуси:**

- Немає публічних каналів (тільки групи)
- Потрібен телефон для реєстрації

**Використання у Will-n-i:**

- Закриті групи практиків (Subscription tier)
- VIP клієнти (особисті консультації)

**Встановити:** https://signal.org

---

### 2. Element (Matrix) (Найкраща для Communities)

**Чому ТАК:**

- ✅ Децентралізований (неможливо заблокувати)
- ✅ Федеративний протокол (як email)
- ✅ Open-source
- ✅ E2E encryption
- ✅ Можна розгорнути свій сервер
- ✅ Інтеграції з іншими платформами (bridges)

**Функції:**

- Публічні та приватні кімнати
- Теми (Spaces) для організації
- Голосові/відео конференції (через Jitsi)
- Боти та інтеграції
- Працює у браузері, desktop, mobile

**Мінуси:**

- UI трохи складніший за шпигунські аналоги
- Немає "каналів" у класичному розумінні (але є кімнати)

**Використання у Will-n-i:**

- Публічна спільнота (Free tier)
- Обговорення серій
- Локальні спільноти Вольних

**Встановити:** https://element.io

---

### 3. Revolt (Найкраща для діскорд-подібного Досвіду)

**Чому ТАК:**

- ✅ Open-source
- ✅ UI дуже схожий на діскорд (легкий перехід)
- ✅ Самохостинг (можна розгорнути свій сервер)
- ✅ Немає збору даних
- ✅ Активна розробка

**Функції:**

- Сервери з каналами (як діскорд)
- Голосові канали
- Ролі та права доступу
- Боти та інтеграції
- Markdown підтримка

**Мінуси:**

- Менша спільнота, ніж діскорд
- E2E encryption ще у розробці (планується)

**Використання у Will-n-i:**

- Структуровані обговорення (топіки)
- Воркшопи та події
- Голосові сесії

**Встановити:** https://revolt.chat

---

### 4. Mattermost (Для Команд)

**Чому ТАК:**

- ✅ Open-source
- ✅ Самохостинг
- ✅ Enterprise-рівень безпеки
- ✅ Інтеграції (GitHub, Jira, тощо)
- ✅ Відмінна організація

**Функції:**

- Канали (публічні/приватні)
- Прямі повідомлення
- Пошук по історії
- File sharing
- Інтеграції та плагіни

**Мінуси:**

- Більше підходить для команд, ніж для публічних спільнот
- Платна версія для розширених функцій

**Використання у Will-n-i:**

- Внутрішня команда проєкту
- VIP клієнти (трансформаційні програми)
- Організація спільних проєктів

**Встановити:** https://mattermost.com

## 🎯 Рекомендована Стратегія для Will-n-i

### Tier 1: Free (Публічна Аудиторія)

**Платформа:** Element (Matrix)

**Чому:**

- Децентралізована (не можна заблокувати)
- Безкоштовна для всіх
- Публічні кімнати для обговорення серій
- Bridges до інших платформ (якщо треба)

**Setup:**

1. Створити Space "Will-n-i: Вільні"
2. Кімнати по темах:
   - #загальне
   - #серії-обговорення
   - #питання
   - #локальні-спільноти (по містах)

---

### Tier 2: Subscription (Practical)

**Платформа:** Signal + Revolt

**Чому:**

- Signal: приватні групи для практикантів
- Revolt: структуровані обговорення та воркшопи

**Setup:**

1. Signal група: "Will-n-i Практики" (до 1000 осіб)
2. Revolt сервер з каналами:
   - #щоденні-ритуали
   - #питання-до-наставників
   - #успіхи
   - 🎤 Голосові канали для weekly calls

---

### Tier 3: VIP (Трансформація)

**Платформа:** Signal або Mattermost

**Чому:**

- Максимальна приватність
- Персональна підтримка
- Структурована робота над проєктами

**Setup:**

1. Signal 1-на-1 з наставником
2. Mattermost team для командних VIP програм

## 💡 Чому Це Важливо?

### 1. Безпека

Використання платформ, що контролюються недружніми державами (РФ) = ризик:

- Витоку даних учасників
- Блокування спільноти
- Використання даних проти учасників

### 2. Етика

Вільні живуть за Природним Правом. Використання інструментів тиранічних режимів суперечить цінностям.

### 3. Практика

якщо проповідуємо свободу, мають використовувати вільні (open-source, децентралізовані) інструменти.
