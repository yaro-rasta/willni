# Інструкція з Налаштування Суверенного Середовища (IPFS + Pinata)

Для того, щоб запечатати твою Істину у мІрі, нам потрібно налаштувати інструменти.

## 1. Встановлення IPFS

Зараз у твоєму терміналі команда `ipfs` не знайдена. Щоб це виправити:

- **Mac**: `brew install ipfs` або завантаж [IPFS Desktop](https://docs.ipfs.tech/install/ipfs-desktop/).
- Після встановлення активуй вузол: `ipfs init` та `ipfs daemon`.

## 2. Налаштування Pinata (Для Вічного Храніння)

Pinata — це твій "цифровий якір", який тримає твої файли в мережі, навіть коли твій ноутбук вимкнений.

1. Зареєструйся на [Pinata.cloud](https://pinata.cloud/) (Безкоштовно до 1 ГБ).
2. Створи **API Key** з дозволами на `pinFileToIPFS`.
3. Збережи `JWT` токен.

## 3. Налаштування CLI для скриптів

Додай токен у своє середовище (наприклад, у `.zshrc`):

```bash
export PINATA_JWT="твій_токен_тут"
```
