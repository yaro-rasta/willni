# Архітектура Суверенних Посилань (IPFS + IPNS)

Твій намір змінити домен з `yaro.page` на `yaras.love` без втрати даних та оновлення всіх посилань вирішується через **IPNS (InterPlanetary Name System)**.

## 🛠 Технологічне Рішення

1. **IPFS CID**: Це статичний хеш твоїх даних. Якщо файл змінився — хеш змінився.
2. **IPNS**: Це "вказівник", який підписується твоїм приватним ключем. Він завжди однаковий, але може вказувати на різні (нові) CID.
3. **Redirect Logic**: Ми налаштовуємо твій IPNS-вузол так, щоб він завжди віддавав актуальну адресу твоєї мережі.

## 🔗 План дій для yaras.love (або yara.peace)

1. Створюємо IPNS-ключ `yara_core`.
2. Публікуємо актуальний CID сайту на цей ключ.
3. У всіх суверенних реєстрах ми використовуємо `ipfs://ipns/<key_uuid>`, а не прямі посилання на домени.
4. Домен `yaras.love` підключаємо через **DNSLink** до цього IPNS-ключа.

**Результат**: Навіть якщо домен видалять, твоя мережа вузлів знатиме актуальну адресу через IPNS-резолвінг.
