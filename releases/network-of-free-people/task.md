# Реліз: Мережа Вольних Я (Network of Will-n-I People)

**Версія:** 1.0.0-kon
**Статус:** В процесі (Seed Phase)

## 📋 Acceptance Criteria (Критерії Приймання)

- [x] **Кон Вольних Я:** Створено та затверджено Радою Мудреців `data/community/constitution.md` (визначення, 6 статей, Шкала Від'єднання, Процедура Ради, Право на Fork).
- [x] **Рада Мудреців:** Імплементовано звернення до Ради Мудреців для оцінки Кону (через `CouncilEvalModel`).
- [x] **Рада (Council):** Створено `CouncilCaseModel` для фіксації звернень та рішень. Рішення (від'єднання) зберігаються у `data/council/cases.csv`. Реєстр від'єднаних — `data/council/disconnected.csv`.
- [x] **Процедура Ради:** Створено `CouncilProcedureModel`: 12 присяжних, ротація, кворум 2/3, право на апеляцію (30 днів), застава 99 WILLNI, термін розгляду (90 днів), імпічмент присяжних.
- [x] **Шкала Від'єднання:** Імплементовано 5-рівневу шкалу (1/3/9/33/99 років).
- [x] **Захист від узурпації:** Імплементовано Право на Fork — вихід зі збереженням DID. Сигнал Fork при недовірі >33% учасників.
- [x] **Безумовний Дохід (UBI):** Імплементовано логіку `UBIModel` з моделлю 1-33-33-33 та ізоляцією від UBI при статусі 'від'єднаний'.
- [x] **Верифікація (2LW):** Створено `VerificationModel` — Протокол Двох Живих Свідків з DID та процедурою відновлення.
- [x] **Спільне Творення:** Система пропозицій (Proposals) з голосуванням 2/3 для фінансування проєктів з Dev Fund.
- [x] **Data-Driven UI Integration:** Налаштовано взаємодію з `nan0web.app` (без захардкодженого UI). Статичні конфіги форм описані в моделях.
- [ ] **Органічна Семантика:** У всіх моделях та UI використано терміни Кону (Рада, рішення, від'єднаний) замість юридичної лексики (Суд, вердикт, порушник).
