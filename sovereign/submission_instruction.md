# Інструкція з відправки суверенних документів до державних органів (Шаблон)

Ця інструкція розроблена для того, щоб ви могли перетворити звичайний текстовий документ (чи документ Word) на юридично значущий, криптографічно захищений доказ вашої волі та відправити його до будь-якої інстанції (наприклад, суду, НКЕК тощо).

## Крок 1. Перетворення документа у PDF

Державні органи найкраще сприймають формат PDF, оскільки він зберігає форматування і його важко непомітно змінити.

### Якщо у вас документ Word (.docx):

Це найпростіший варіант.

1. Відкрийте ваш документ у Microsoft Word (або іншій програмі).
2. Натисніть **Файл** -> **Друк** (або Ctrl+P).
3. У списку принтерів виберіть **"Microsoft Print to PDF"** (або "Зберегти як PDF").
4. Натисніть **Друк** і виберіть місце, куди зберегти готовий PDF-файл.
   _(Також можна використати Файл -> Зберегти як -> обрати формат PDF)._

### Якщо у вас текстовий файл Markdown (.md):

1. Відкрийте будь-який безкоштовний онлайн-конвертер (наприклад, [markdowntopdf.com](https://markdowntopdf.com/) або [dillinger.io](https://dillinger.io/)).
2. Вставте туди текст вашого документа.
3. Натисніть кнопку **"Export to PDF"** (або "Зберегти як PDF").
4. Збережіть отриманий файл на комп'ютер.

## Крок 2. Накладання електронного підпису (PGP)

Щоб довести, що документ не змінювався і написаний саме вами, його треба підписати вашим PGP-ключем. Процес відрізняється залежно від операційної системи:

### Для Windows (Kleopatra)

1. Встановіть пакет [Gpg4win](https://gpg4win.org/), який включає програму **Kleopatra**.
2. Відкрийте Kleopatra.
3. Натисніть кнопку **"Sign/Encrypt"** (Підписати/Зашифрувати) на верхній панелі.
4. Виберіть ваш PDF-файл.
5. Переконайтеся, що стоїть галочка біля **"Sign"** (Підписати) і вибрано ваш ключ.
6. Натисніть "Sign". Програма попросить пароль від вашого ключа.
7. В результаті поруч із PDF-файлом з'явиться новий файл підпису з розширенням `.sig` (наприклад, `document.pdf.sig`).

### Для MacOS (GPG Keychain)

1. Встановіть [GPG Suite](https://gpgtools.org/).
2. Після встановлення у вас з'явиться програма **GPG Keychain**.
3. Знайдіть ваш PDF-файл у Finder.
4. Натисніть на файл **правою кнопкою миші** -> виберіть **"Services"** (Служби) -> **"OpenPGP: Sign"**.
5. Виберіть ваш ключ, введіть пароль і натисніть "OK".
6. Поруч з'явиться файл підпису (зазвичай `.sig` або `.asc`).

### Для Linux (Ubuntu / Mint / Debian)

1. Ви можете використовувати термінал або графічну програму. Найпростіше — термінал.
2. Відкрийте термінал у папці з файлом.
3. Введіть команду: `gpg --detach-sign --armor назва_файлу.pdf`
4. Введіть пароль від вашого ключа.
5. З'явиться файл `.asc` — це і є ваш підпис.

## Крок 3. Завантаження до "Вічної мережі" (IPFS через Pinata)

Ми фіксуємо документ у децентралізованій мережі, щоб він не міг "загубитися" або бути видаленим цензурою.

1. Зайдіть на сайт **[pinata.cloud](https://app.pinata.cloud/)** та увійдіть у свій акаунт.
2. Натисніть кнопку **"Upload"** (Завантажити) -> **"File"**.
3. Виберіть ваш PDF-файл і завантажте його.
4. Повторіть це для файлу підпису (`.sig` або `.asc`).
5. Після завантаження напроти кожного файлу з'явиться **CID** (Content Identifier). Це унікальний хеш файлу. Скопіюйте їх.

---

## Крок 4. Відправка електронного листа

Тепер формуємо офіційне звернення. Щоб документ гарантовано не проігнорували, рекомендується надсилати його не лише основному адресату, але й **у копії (CC)** контролюючому органу (наприклад, Уповноваженому з прав людини, Урядовій гарячій лінії або прокуратурі).

**Кому:** `[email_основної_установи@gov.ua]`  
**Копія (CC):** `[email_контролюючого_органу@gov.ua]`  
**Тема:** Позов до суду / Офіційне звернення від [Ваше Прізвище та Ініціали]

**Текст листа (приклад для позову до суду):**

> Доброго дня.
>
> Направляю офіційний позов до суду (або скаргу) щодо [коротко суть питання, наприклад: порушення прав споживача / неправомірних дій такої-то особи чи компанії].
>
> У додатках до цього листа знаходиться:
>
> 1. Файл позову/скарги у форматі PDF.
> 2. Файл криптографічного PGP-підпису.
>
> З метою унеможливлення підробки та знищення доказів, оригінали цих документів також зафіксовані у децентралізованій мережі IPFS:  
> CID документа: [вставте сюди CID вашого PDF з Pinata]  
> CID підпису: [вставте сюди CID вашого підпису з Pinata]
>
> Прошу зареєструвати дане звернення/позов відповідно до чинного законодавства та надати відповідь у встановлені терміни на цю електронну адресу.
>
> З повагою,  
> Жива Людина [Ваше Ім'я], один з Народу  
> ([Прізвище, Ім'я, По батькові])

**Важливо:** Обов'язково прикріпіть до листа ваш `pdf` файл та файл підпису `.sig`/`.asc` перед відправкою.
