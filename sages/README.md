# 🧠 Рада Мудреців (Council of Sages)

Ця директорія містить ієрархічну базу знань, згенеровану через накладання нашого контексту на ментальні матриці великих мислителів та інженерів минулого (Сократ, Макіавеллі, Сковорода, Леонардо Да Вінчі, Тесла, Сірко, Стів Джобс, Борис Патон). Увесь синтез жорстко фільтрується через 4 Закони Логіки Аристотеля для уникнення емоцій та збереження кристальної істини.

## 📂 Структура Бази Знань

Архітектура побудована за фрактальним принципом:
`Категорія Мислення` ➡️ `Напрямок Мислення` ➡️ `Документи`

```text
/sages
  ├── /economy                  # Категорія мислення (Економіка)
  │     └── /tax_terror         # Напрямок мислення (Податковий терор)
  │           ├── source.md     # Першоджерело, базис, ідея для аналізу
  │           └── synthesis.md  # Згенерований висновок Ради Мудреців
  ├── /law                      # Категорія мислення (Право)
  └── /philosophy               # Категорія мислення (Філософія)
```

Така ієрархія дозволяє нам зберігати "заповіти" від людей, які жили багато століть тому, та через їхню точку зору знаходити фундаментальні стратегії перемоги у сучасному світі.
